# Country List App

An Android application developed using **Kotlin** and **Jetpack Compose** as part of a mobile application development assignment.

The application displays information about 10 countries in a scrollable list, including their flags, names, capitals, and currencies.

## Features

- Displays 10 countries using LazyColumn.
- Presents country information in Card components.
- Uses Row and Column for UI layout.
- Displays country flags from local drawable resources.
- Provides a scrollable interface for browsing country information.

## Technologies

- Kotlin
- Jetpack Compose
- Android Studio
- Gradle

## Project Information

This project was developed as an academic assignment to practice Android UI development with Jetpack Compose, including list rendering, reusable UI components, and layout management.
